# Escuela Nacional Preparatoria No. 4 “Vidal Castañeda y Nájera”

Repositorio enfocado en el manejo y administración de información académico-administrativa dentro de la Escuela Nacional Preparatoria No. 4 de la UNAM.

## Objetivo
Desarrollar y documentar herramientas tecnológicas que apoyen la organización, automatización y procesamiento de información institucional mediante Python y otras tecnologías de análisis de datos.

## Áreas de trabajo
- Gestión de bases de datos académicas
- Automatización de procesos administrativos
- Procesamiento de archivos Excel
- Organización de horarios
- Validación de información
- Generación de reportes
- Integración y análisis de datos

## Tecnologías utilizadas
- Python
- SQL
- Pandas
- Jupyter Notebook
- Excel

## Contexto
Este repositorio surge a partir de necesidades reales relacionadas con la logística académica y administrativa del plantel, buscando optimizar procesos y reducir tareas repetitivas mediante herramientas computacionales accesibles.
